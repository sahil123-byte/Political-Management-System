# Political Management System - Frontend

React + Vite frontend for the Political Management System.

## Tech Stack
- React 19 + Vite
- React Router
- Axios
- Recharts (analytics charts)
- React Icons

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Start the dev server:
   ```
   npm run dev
   ```
   Runs at `http://localhost:5173`

3. Make sure the backend is running first at `http://localhost:8080` (see the backend repo).

## Default login
- Email: `admin@gmail.com`
- Password: `123456`

## Features
- Role-based access (ADMIN / MANAGER / MEMBER) with scoped data visibility
- Full CRUD for states, districts, constituencies, booths, parties, members, voters, campaigns, events, complaints, feedback
- Image uploads (profile photos, party logos)
- Dashboard, reports, and analytics with live data
- Dark mode
- Mobile-responsive layout
