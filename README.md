Political Management System

A full-stack web application for managing users, members, political organizations, parties, campaigns, events, voters, complaints, and administrative activities through a centralized platform.

🚀 Features

* Role-based access control for Admin, Manager, and Member
* Secure JWT-based authentication
* User, member, party, and organization management
* State, district, constituency, and booth management
* Campaign and event management
* Voter and complaint management
* Notifications and feedback management
* Dashboard and analytics
* Reports and data management
* RESTful API integration
* Responsive React.js interface

🛠️ Tech Stack

Backend: Java, Spring Boot, Spring Security, JWT, REST APIs, MySQL, JDBC, Maven

Frontend: React.js, JavaScript, HTML5, CSS3, Vite

Tools: Git, GitHub, Postman, MySQL, IntelliJ IDEA / Eclipse

⚙️ Getting Started

Prerequisites

* Java 17+
* Maven
* Node.js and npm
* MySQL
* Git

Clone the Repository

git clone https://github.com/sahil123-byte/Political-Management-System.git
cd Political-Management-System

Run Backend

cd "PMS- Backend"
./mvnw spring-boot:run

Run Frontend

Open another terminal:

cd PMS-frontend
npm install
npm run dev

Then open the local URL provided by Vite.

🔐 Configuration

Configure your database and required environment variables before running the backend.

JWT_SECRET=<your-jwt-secret>
ADMIN_DEFAULT_PASSWORD=<your-admin-password>

Do not commit passwords, JWT secrets, API keys, or other sensitive credentials to GitHub.
